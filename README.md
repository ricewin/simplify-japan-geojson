# simplify-japan-geojson

## Simplify the Geo-format Prefectures and municipalities of Japan

### 日本の都道府県と市区町村の GeoJSON を簡素化しました

フォーマット：GeoJSON, TopoJSON

国土数値情報ダウンロードサイトにて提供されている国土数値情報、行政区域データを軽量化しています。

### オープンデータ

本コンテンツを利用する際は、必ず、国土数値情報ダウンロードサイトコンテンツ利用規約（政府標準利用規約準拠版）をご確認ください。  
※本データを二次利用する場合には、国土地理院に申請等必要な場合があります。

出典：[国土交通省国土数値情報ダウンロードサイト](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html)

---

### 軽量化

データの軽量化は [Mapshaper](https://mapshaper.org/) を使用しました。主なパラメーターは以下になります。

- Dissolve
  - 全国、地方: N03_001,N03_007
  - 北海道の振興局: N03_001,N03_002,N03_007
  - 都道府県: N03_001,N03_003,N03_004,N03_007
- Simplify
  - 簡略化アルゴリズム: Visvalingam / weighted area（Mapshaper のデフォルト）
  - 全国、北海道の振興局: 0.5 %
  - 地方: 1 %
  - 都道府県: 5 %

### CLI バッチ（自動化）

ZIP を解凍した Shapefile 一式を入力として、Mapshaper の CLI バッチで自動生成します。

#### 実行環境

- Node.js（最新版想定）
- 依存関係はローカルインストール
- `scripts/mapshaper_batch.sh` は `node_modules/.bin/mapshaper` を優先して使用

```bash
npm install
```

#### 入力データの準備

1. 上記の出典ページから全国一括の ZIP を取得し解凍
2. 解凍後の Shapefile 一式を `input/` に配置

#### 実行

```bash
bash scripts/mapshaper_batch.sh
```

入力ファイルを変更する場合は `INPUT_SHAPEFILE` を指定します。

```bash
INPUT_SHAPEFILE=/path/to/N03-20250101.shp bash scripts/mapshaper_batch.sh
```

- 入力（自動検出）: input/N03-\*.shp
- 出力: GeoJson/ と TopoJson/
- バッチ: scripts/mapshaper_batch.sh
- 処理マトリクス: scripts/targets.tsv

政令指定都市は `N03_004` を結合対象として扱い、結合後に簡略化します。結合ルールは、`N03_004` の市区町村名が一致する場合に行政区域コード`N03_007`を政令指定都市のコードに揃える方式です（対象コードはスクリプト内の一覧）。
